# AI Code Reviewer

Кросплатформна система автоматичного рев'ю коду на основі AI-агента: REST API (FastAPI) та React-клієнт у вигляді PWA, який працює на Windows, Linux, macOS, Android та iOS і встановлюється як застосунок.

Код перевіряє статичний лінтер (Semgrep, pyflakes), а AI-агент (Google Gemini) пояснює знахідки, додає власні зауваження й може запропонувати виправлений файл. Підтримуються Python, JavaScript і TypeScript (повний аналіз), інші мови перевіряються лише AI.

**Увесь проєкт, повний опис, інструкції із запуску та перелік API знаходяться в папці [`ai-code-reviewer/`](./ai-code-reviewer). Почніть з [README проєкту](./ai-code-reviewer/README.md).**

## Швидкий старт

```bash
cd ai-code-reviewer
cp .env.example .env      # впишіть GEMINI_API_KEY
docker compose up -d --build
```

Після запуску клієнт доступний на http://localhost:5173, документація API на http://localhost:8000/docs.

## Основне

- Рев'ю коду з оцінкою, коментарями за категоріями (баги, безпека, стиль, продуктивність) і посиланнями на джерела
- Чат з AI про код і питання до окремих коментарів
- Генерація виправленого коду з копіюванням і завантаженням
- Завантаження коду вставкою, з файлу або зі списку публічних репозиторіїв GitHub
- Реєстрація з підтвердженням пошти, вхід через Google і GitHub
- Асинхронна обробка (Celery + Redis), запуск однією командою через Docker Compose
